# Разбор «Zombies Aren't Real» → Zombie Fuckers

Метод — из скилла [reverse-engineer-anything (REA)](https://github.com/morluto/rea/blob/main/.agents/skills/reverse-engineer-anything/SKILL.md):
чек-лист вопросов, журнал находок с источником и типом доказательства, явное разделение
**наблюдений**, **выводов** и **неизвестного**, проверка чек-листа перед сборкой.

## Почему без инструментов REA

REA анализирует поставляемые артефакты: бинарники, пакеты, Electron, APK, рантайм в браузере.
У «Zombies Aren't Real» (Jogamedev, Steam app 5185890) на момент разбора нет ни демо, ни сборки
в открытом доступе: игра в статусе «Coming soon to Early Access», 1.0 запланирована на март 2027.
Целевого артефакта нет, поэтому `open_binary` / `analyze_javascript_application` неприменимы.
По правилу скилла («when the user asks to build something, use normal coding tools and separate
observed behavior from design choices») исследование шло по открытым материалам, а игра собрана
обычными средствами. Ни кода, ни ассетов оригинала в проекте нет.

| Механика оригинала | У нас | Отличия (решения дизайна) |

### Своё, чего в оригинале не видно

- Скрытые носители в толпе с инкубацией 2–35 с и бегуны (12 % быстрых зомби).
- Спецзания в safe zone: медпункт (лечит заражённых до превращения), мастерская (ремонт), казарма (рекруты).
- Пункты эвакуации, вывозящие людей с карты с ограниченной пропускной способностью.
- Поворот карты, 2.5D-проекция по реальным высотам, звук без файлов (Web Audio).

## Остающиеся неизвестные

Как именно работают Corridor, Hold, Missile, APC; что значит таймер «ZOMBIES DIE IN N»; есть ли типы
зомби; как растут бюджеты между сценариями; параметры юнитов кроме миномёта (цены между сборками
отличаются, все цифры оригинала — предварительные).
