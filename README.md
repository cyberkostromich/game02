# Zombie Fuckers

Браузерная стратегия сдерживания зомби-орды на реальной карте Мидтауна Манхэттена.
Вдохновлена игрой [Zombies Aren't Real](https://store.steampowered.com/app/5185890/Zombies_Arent_Real/) (Jogamedev):
механики восстановлены по открытым описаниям (см. [`docs/reverse-engineering.md`](docs/reverse-engineering.md)),
код, карта и графика — свои.

## Как играть

1. Выберите миссию. На карте отмечен очаг и зона вокруг него, куда до начала вспышки войти нельзя.
2. Расставьте силы на бюджет миссии: снайперы (на улице или на крыше — с высотки видно поверх домов),
   штурмовики в зданиях, турели, миномёты, баррикады, пункты эвакуации.
3. Вокруг каждого пункта эвакуации — safe zone. Зданиям в ней можно дать специализацию:
   медпункт (лечит заражённых до превращения, чинит бойцов), мастерская (ремонт баррикад и техники),
   казарма (вооружает мирных — рекруты сами отстреливаются).
4. «Начать» — заражение пошло. Можно докупать силы, вызывать вертолёт и авиаудар (бомбит и мирных).
5. Победа — когда не осталось ни зомби, ни заражённых. Звёзды — за долю спасённых (50/70/85 %),
   звёзды тратятся на усиления.

Управление: перетаскивание — карта, колесо/щипок — масштаб, касание — поставить выбранное или выбрать юнит,
линия — баррикада/заход авиаудара. Клавиши: `1`–`9` инструменты, `Пробел` — старт/пауза, `Esc` — отмена.

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # vitest: симуляция
npm run test:e2e   # Playwright: смоук на продакшен-сборке
npm run build      # dist/
npm run map:build -- <папка с тайлами OSM map.json>   # пересобрать карту
```

Устройство:

- `src/sim/` — симуляция без DOM: сетка проходимости из полигонов OSM (`grid.ts`), поля потоков
  (`field.ts`, алгоритм Дейкстры с корзинами), агенты как массивы (`world.ts`), юниты и обстрел (`units.ts`),
  safe zone и рекруты (`support.ts`). Все числа баланса — в `src/config.ts`. Вся случайность — через сид.
- `src/render/` — карта в 2.5D на Canvas 2D (`mapLayer.ts`), толпа — одним вызовом WebGL2 (`agents.ts`),
  юниты и эффекты (`overlay.ts`).
- `tools/build-map.mjs` — конвертер тайлов OpenStreetMap API в компактный `public/maps/midtown.json`.
