# Zombie Fuckers

Браузерная стратегия сдерживания зомби-орды на реальной карте Мидтауна Манхэттена.
Играть: **https://cyberkostromich.github.io/game02/**
Вдохновлена игрой [Zombies Aren't Real](https://store.steampowered.com/app/5185890/Zombies_Arent_Real/) (Jogamedev):
механики восстановлены по открытым описаниям (см. [`docs/reverse-engineering.md`](docs/reverse-engineering.md)),
код, карта и графика — свои.

## Как играть

1. Выберите миссию. Зелёный круг — очаг: до начала вспышки туда ничего не поставить.
2. Расставьте силы на бюджет миссии:
   - **Оборона**: снайперы (на улице или на крыше — с высотки видно поверх домов), штурмовики в зданиях,
     турели, миномёты, минные поля, баррикады (мирные проходят, зомби ломают), шипы.
   - **Тыл**: safe zone (растяните прямоугольник), пункты эвакуации, а в safe zone — медпункт,
     мастерская, казарма. Внутри целой safe zone бойцы пополняют патроны, вне её — только свой магазин.
   - **Поддержка** (в бою, с перезарядкой): вертолёт, авиаудар, газ, напалм, десант, «К оружию!».
3. «Начать» — вспышка пошла. За каждого убитого зомби +$2. Выбранный юнит можно прокачать до 3-го уровня.
4. Победа — когда не осталось ни зомби, ни заражённых. Звёзды — за 50/70/85 % спасённых,
   звёзды тратятся на усиления.

Управление: перетаскивание — карта; колесо/щипок — масштаб; поворот двумя пальцами или `,` `.` —
вращение на 90°; касание — поставить или выбрать; линия — баррикада/шипы/safe zone/заход авиаудара.
Клавиши: `1`–`7`, `B E H J K`, `Z C V N P T` — инструменты; `U` — прокачать, `X` — снять;
`Пробел` — старт/пауза; `F1`–`F5` — скорость ½×–8×; `M` — звук; `Esc` — отмена.

Как разбирался оригинал — [`docs/reverse-engineering.md`](docs/reverse-engineering.md).

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # vitest: симуляция
npm run test:e2e   # Playwright: смоук на продакшен-сборке
npm run build      # dist/
npm run map:build -- <папка с тайлами OSM map.json>   # пересобрать карту
```

Устройство:

- `src/sim/` — симуляция без DOM: сетка проходимости из полигонов OSM (`grid.ts`), поля потоков
  (`field.ts`, алгоритм Дейкстры с корзинами), агенты как массивы (`world.ts`), юниты и обстрел (`units.ts`),
  safe zone и рекруты (`support.ts`), способности (`abilities.ts`). Все числа баланса — в `src/config.ts`. Вся случайность — через сид.
- `src/render/` — карта в 2.5D на Canvas 2D с поворотом (`mapLayer.ts`), толпа — одним вызовом WebGL2 (`agents.ts`),
  юниты и эффекты (`overlay.ts`). Звук синтезируется в `src/audio.ts`.
- `tools/build-map.mjs` — конвертер тайлов OpenStreetMap API в компактный `public/maps/midtown.json`.
